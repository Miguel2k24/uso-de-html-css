Backend

El backend es la parte interna o “no visible” de una aplicación o sitio web, encargada de procesar la lógica, gestionar los datos, controlar la seguridad y comunicarse con las bases de datos y los servidores. A diferencia del frontend, que se ocupa de la interfaz visual que el usuario ve, el backend se encarga de hacer funcionar todo lo que ocurre detrás de escena.
