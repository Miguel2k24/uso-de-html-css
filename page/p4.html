FrontEnd

El frontend es la parte visible y accesible de una aplicación o sitio web, es decir, todo aquello con lo que el usuario interactúa directamente desde su navegador o dispositivo. Representa la interfaz gráfica y la experiencia de usuario (UX), encargándose de transformar los datos y funcionalidades del sistema en elementos visuales comprensibles, atractivos y fáciles de usar.
